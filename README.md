# 🏆 BrunnerCTF 2026

**BrunnerCTF 2026** was a 48-hour online Jeopardy-style Capture The Flag competition organized by **Brunnerne** and hosted from **21–23 August 2026**. The event featured a wide range of cybersecurity challenges across categories including **Crypto, Web, Reversing, Forensics, Mobile, Pwn, OSINT, Misc, Boot2Root, and Onboarding**.

This repository contains my **solutions, analysis, scripts, and detailed writeups** for the challenges I solved during the competition.

## 📂 Categories

The writeups in this repository cover challenges from categories such as:

* 🔐 **Cryptography**
* 🌐 **Web Security**
* 🔎 **Forensics**
* ⚙️ **Reverse Engineering**
* 📱 **Mobile Security**
* 🧩 **Miscellaneous**
* 🐚 **Boot2Root**
* 📝 **Onboarding**

## 🎯 Purpose

The main goal of this repository is to document my learning process and preserve the techniques used to solve the challenges. Each writeup focuses not only on obtaining the flag, but also on understanding **why the vulnerability or technique worked**.

> **Learn → Analyze → Exploit → Document**

All writeups are created for **educational and cybersecurity learning purposes**.
